# Чертежи к задачам

Схематичные SVG для геометрических задач рисуются кодом, а не вручную: правила проекта
(`lib.drawingIssues`) одни и те же для всех, и чертёж всегда собирается из тех же чисел, что и условие.

## Правила (то, что проверяет робот)

- На геометрическом чертеже подписаны **только вершины**, заглавными латинскими буквами, и только те,
  что названы в условии. Нет названий в условии — чертёж без подписей.
- Никаких длин, углов числом, единиц, «?», строчных подписей: всё числовое живёт в тексте условия.
  Равные отрезки и углы показывают чёрточками (`tick`) и дугами (`arcAng`), прямой угол — квадратиком (`right`).
- Индексы вроде `A₁` пишутся символом-подстрочником, не цифрой (цифра в подписи — «число на чертеже»).
- Высоты, медианы, диагонали и вспомогательные линии — пунктиром. Ответ на чертеже не показывать.
- Графики и диаграммы — исключение: там числа на осях нужны (эти скрипты их не рисуют).

## Как пользоваться

```bash
node scripts/figs/candidates.mjs 8,9          # какие задачи ждут чертежа (пишет out/candidates.json)
# описать чертёж в specs*.mjs: id задачи → () => new Fig()….  (помощники: figlib.mjs)
node scripts/figs/build.mjs specs9c           # собрать, проверить роботом, получить листы out/sheet-*.html
# открыть лист в браузере и просмотреть глазами
node scripts/figs/upload.mjs                  # сухой прогон
node scripts/figs/upload.mjs --apply          # залить и прописать condition_image (только там, где пусто)
node scripts/audit-tasks.mjs --grade 8        # убедиться, что робот доволен
```

`upload.mjs` кладёт файл под именем `condition/task-<id>-v1.svg`. Чтобы **заменить** чертёж, который уже
привязан к задаче, нужен новый файл под другим именем (`-v2`): публичные адреса Supabase кеширует Cloudflare,
перезаписанный файл ещё долго отдаётся старым.

## Что внутри

- `figlib.mjs` — класс `Fig` (многоугольники, отрезки, окружности, эллипсы, дуги углов, метки, подписи вершин),
  векторные помощники (`foot`, `inter`, `circumcircle`, `incircle`, `regular`…) и тела в косоугольной проекции
  (`prism`, `cylinder`, `addCylinder`) с невидимыми рёбрами пунктиром.
- `specs8a/8b/8c`, `specs9a/9b/9c` — 145 чертежей к задачам 8 и 9 классов (30.09.2026); ключ — id задачи.
- `build.mjs`, `upload.mjs`, `candidates.mjs` — сборка, загрузка, поиск задач без чертежа.
- `out/` — результат сборки, в git не хранится (файлы лежат в бакете `task-images`).
