# MathTasks (mathtasks.lv)

Сборник задач по математике для Латвии (Skola2030): статические страницы на Vite, воркер Cloudflare (`worker/`), база Supabase. Тексты интерфейса — латышский и русский (`public/i18n.js`). Задачи, темы и подтемы лежат в базе, а не в репозитории.

- **Выкладка автоматическая:** Cloudflare собирает и выкладывает сайт после каждого push в master. Поэтому push — это выкладка; вручную (`npm run deploy`, `wrangler deploy`) не выкладывать.
- **База одна, она же рабочая.** Тестовой нет. Ключ `service_role` лежит в `.env`; скрипты проекта и скилл `add-tasks` пишут в неё по-настоящему.
- Проверки: `npm test` (до push), `npm run verify` (ответы задач), локально — `vite-dev` из `.claude/launch.json`.
- Работает несколько сессий в одной папке: в коммит берём только свои правки, чужие незакоммиченные не трогаем.

## Модели и роли

Основная сессия ведёт задачу, раздаёт работу помощникам, сама пишет код красной зоны и принимает чужую работу.
Помощники — `.claude/agents/`:

| Помощник | Модель | Что делает | Меняет код |
| --- | --- | --- | --- |
| `researcher` | Haiku | находит места в коде, возвращает `файл:строка` | нет |
| `planner` | Fable | план функции, архитектура | нет |
| `implementer` | Sonnet | зелёная зона по точному заданию | да, без коммита |
| `reviewer` | Fable | ревью диффа перед коммитом | нет |

**Зона задачи определяется по файлам, которые она трогает, а не по тому, насколько она выглядит простой.**

- **Красная зона** — база, воркер, секреты, выкладка, данные учеников, задачи в базе: `supabase/**`, `worker/**`,
  `wrangler.jsonc`, `public/_headers` (защитные заголовки), `public/sw.js` (ошибка оставляет посетителям старый сайт),
  `public/profile.js`, `public/progress-sync.js`, `public/admin.js`, `admin.html`, `public/slug-redirects.json`,
  `vite.config.js`, `scripts/**`, `.env*`, `.claude/**` (страж, помощники, скилл `add-tasks`). Любая запись в базу и
  правка условий, ответов и решений задач — только скриптами с проверками (`add-tasks`, `verify`), не руками.
  Код пишет основная сессия сама (не `implementer`); перед коммитом — `reviewer`, всегда, даже для одной строки.
- **Зелёная зона** — всё остальное: страницы, стили, тексты, клиентский код интерфейса, тесты. Можно отдать
  `implementer` с точным заданием (файлы, что сделать, как проверить). Ревью — `/code-review` для заметных правок,
  `reviewer` — для крупных.

Порядок:
- Задача на 1–3 файла в зелёной зоне — без цепочки, делать сразу.
- Новая функция, больше 3 файлов, архитектура или красная зона — сначала `planner`, план показать владельцу,
  работать после его «да».
- `reviewer` получает задание и дифф, а не объяснение автора, почему всё правильно.
- Находка `researcher` — это адрес, а не решение: «нигде не используется», «можно удалить» проверяет основная сессия сама.
- `implementer` вернул «нужна правка в красной зоне» — эту часть делает основная сессия.
- Помощники не коммитят, не пушат и не выкладывают; это делает основная сессия.

**Правила интерфейса, которые уже ломали:** тексты сразу на двух языках; текст с тегами — через `data-i18n-html`;
значки кнопок — SVG, а не эмодзи (`nachala-clean.js` вырезает их); у изменённого скрипта или стиля новый `?v=` в
подключении; правило вне слоя в `nachala.css` перебивает слой.

**Страховка** — `.claude/hooks/guard-prod.mjs` (подключён в `.claude/settings.json`, проверки — `tests/guard-prod.test.js`):
перед каждой командой и записью файла останавливает ручную выкладку (`npm run deploy`, `wrangler deploy|secret|delete…`),
`npm run restore` (перезапись базы из копии), `supabase db push|reset|link`, запись в `.env` и принудительный push;
спрашивает владельца про `git push`, скрипты с `--apply`, записи в базу по HTTP и правку `wrangler.jsonc` и самого стража.
Части команды, которые только читают или работают с git, он пропускает. Запуски `add-tasks` и `add-papers`
(автопоток контрольных, ядро записи — `scripts/lib/paper-core.mjs`, общее с `scripts/add-paper.mjs`) не трогает: они идут по
расписанию без людей. Хук остановил команду — не обходить: подготовить шаги и сказать владельцу, что запустить.
Проверка, что хук работает: `echo wrangler deploy` должен быть остановлен.
