# Taxonomy каталога MathTasks

Курс → раздел → подтема по программе VISC/Skola2030. **Klase** — отдельная ось фильтрации, независимая от раздела: подтема из раздела «Ģeometrija» может относиться к 7 классу, а соседняя — к 9. Несколько чисел означают, что тема возвращается в программе с углублением.

**Кросс-теги** — для задач на стыке разделов: тригонометрическое уравнение живёт в разделе «Trigonometrija», но помечается тегом `algebriskie-parveidojumi`, чтобы находиться и через алгебру.

Подтем всего: **167**.
