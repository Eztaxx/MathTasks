# Приложение MathTasks в Google Play

Приложение — это сам сайт mathtasks.lv в оболочке TWA (Trusted Web Activity).
Оно открывается в Chrome без адресной строки, со своей иконкой и уведомлениями.
Отдельного кода у приложения нет: всё, что выкладывается на сайт, сразу
появляется и в приложении.

Что это даёт:

- **Прогресс общий с сайтом.** Профиль ученика (ник + код переноса) работает так
  же, как на сайте. TWA делит хранилище с Chrome на телефоне, поэтому у кого профиль
  уже есть в Chrome, тот увидит его в приложении сразу.
- **Без сети** работают тренажёры и просмотренные задачи (service worker, `public/sw.js`).
- **Напоминание позаниматься** приходит от имени приложения
  (делегирование уведомлений TWA).

Пакет: **`lv.mathtasks.app`**. Имя пакета в Google Play поменять нельзя.

## 1. Сервер — один раз

### Миграции Supabase

SQL Editor → New query → Run, по порядку:

1. `supabase/migrations/032_progress_version.sql` — запись прогресса с проверкой
   версии: два устройства больше не затирают друг друга.
2. `supabase/migrations/033_push_reminders.sql` — подписки на напоминание.

До миграций сайт работает как раньше. Переключатель напоминания появится в
карточке профиля сам, когда есть и миграция 033, и ключи VAPID (ниже). Порядок:
сначала 033, потом ключи — ключи без 033 дают ошибку в журнале воркера каждый час.

### Ключи для напоминаний

```bash
node scripts/make-vapid.mjs
```

Скрипт печатает два ключа. Сохраните их в секреты воркера:

```bash
npx wrangler secret put VAPID_PUBLIC_KEY
```

```bash
npx wrangler secret put VAPID_PRIVATE_KEY
```

Проверка: https://mathtasks.lv/api/push/key отдаёт `{"key":"…"}`.

**Ключи не меняйте:** иначе все подписки перестанут работать, и ученикам придётся
включать напоминание заново.

Напоминания рассылаются раз в час, на второй минуте (`"2 * * * *"` в
`wrangler.jsonc`). Итог каждого запуска виден в журнале воркера:
`npx wrangler tail`.

## 2. Пакет для Google Play — PWABuilder

1. Откройте https://www.pwabuilder.com, введите `https://mathtasks.lv`,
   нажмите **Package for stores → Android → Google Play**.
2. Настройки. Названия полей в PWABuilder могут немного отличаться, ориентируйтесь
   на смысл:

   | Поле | Значение |
   |---|---|
   | Package ID | `lv.mathtasks.app` |
   | App name / Short name | `MathTasks` |
   | App version / Version code | `1.0.0` / `1` — при каждой новой сборке код +1 |
   | Host / Start URL | `mathtasks.lv` / `/` |
   | Display mode | Standalone |
   | Notification delegation | **включить** |
   | Monochrome icon | `https://mathtasks.lv/icons/badge-96.png` |
   | Fallback behavior | Custom Tabs |
   | Signing key | **New** — имя, организация `MathTasks`, страна `LV` |

   Цвета и иконки PWABuilder берёт из `manifest.webmanifest`.
3. Скачайте архив. В нём:
   - `.aab` — это загружается в Google Play;
   - `signing.keystore` и `signing-key-info.txt` — ключ загрузки и пароли;
   - `assetlinks.json` — отпечаток ключа.

**Ключ подписи и пароли храните вне репозитория, с резервной копией.** Без них
новую версию приложения не загрузить. Если ключ всё же потерян, при Play App
Signing ключ загрузки можно сбросить через поддержку Google, но это дни ожидания.

## 3. Подтверждение, что сайт и приложение — одно целое

Без этого приложение покажет адресную строку браузера.

1. Возьмите SHA-256 из `assetlinks.json` в архиве PWABuilder — строка вида
   `AB:CD:…`, 32 пары.
2. После загрузки в Play Console возьмите второй отпечаток: **Setup → App integrity
   → App signing key certificate → SHA-256**. Google подписывает приложение своим
   ключом, и без этого отпечатка установленное из Play приложение тоже покажет
   адресную строку.
3. Сохраните оба через запятую:

   ```bash
   npx wrangler secret put ANDROID_CERT_SHA256
   ```

4. Проверка:
   - https://mathtasks.lv/.well-known/assetlinks.json — пакет и отпечатки;
   - проверка Google:
     `https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://mathtasks.lv&relation=delegate_permission/common.handle_all_urls`

Файл отдаёт воркер (`assetLinks` в `worker/index.js`). Пока секрета нет — 404.

## 4. Google Play Console

- **Аккаунт разработчика** — 25 $ один раз.
  - **Личный** аккаунт, созданный после 13.11.2023, перед публикацией обязан пройти
    закрытый тест: **12 тестировщиков, 14 дней подряд**. С 2026 года Google ещё и
    проверяет, что тестировщики реально пользовались приложением. Соберите
    12 человек заранее: учителя, ученики постарше, знакомые — разные аккаунты
    Google, настоящие телефоны.
  - **Аккаунт организации** (например, школы) от этого теста освобождён.
- **Политика приватности — обязательна.** Отдельной страницы на сайте пока нет.
  Нужна страница на LV и RU: что хранится (ник, прогресс, анонимный вход, подписка
  на напоминание — без имени и почты), где (Supabase, ЕС), как удалить (кнопка
  «Удалить профиль»), контакт.
- **Target audience.** Среди пользователей есть дети младше 13 лет (классы 1–12).
  Если в возрастных группах отметить до 13, действуют правила Families: политика
  приватности, никакой рекламы и сторонних SDK, подходящий контент. У приложения
  нет ни рекламы, ни SDK — это выполнимо, но отмечайте честно.
- **Data safety:**
  - какие данные собираются: ник, данные о прогрессе («App activity»),
    анонимный идентификатор входа, подписка на уведомления;
  - всё передаётся по HTTPS;
  - удалить можно в самом приложении;
  - данные не продаются и не передаются третьим лицам.
- **Витрина:**
  - иконка 512×512 — `public/icons/icon-512.png`;
  - баннер 1024×500;
  - 2–8 скриншотов телефона;
  - короткое и полное описание на LV и RU;
  - категория «Образование».

## 5. Проверка на телефоне

1. Установите приложение из закрытого теста.
2. Адресной строки нет. Если есть — см. раздел 3: не хватает отпечатка или секрет не сохранён.
3. «Мой прогресс» → профиль на месте, если он был в Chrome. Или «У меня уже есть
   профиль» → код переноса с другого устройства.
4. В карточке профиля включите «Напоминать позаниматься» и выберите ближайший час.
   - Android 13+ спросит разрешение на уведомления.
   - Если запроса не было: Настройки → Приложения → MathTasks → Уведомления → разрешить.
5. Не занимайтесь в этот день — в выбранный час, в начале часа, придёт напоминание.
   Нажатие открывает тренажёр.

## Обновления

- **Сайт** обновляется как обычно — пуш в master, Cloudflare выкладывает сам.
  Приложение подхватит изменения при следующем запуске.
- **Пакет** пересобирать нужно, только если меняются имя, иконка, цвета или
  настройки PWABuilder. Каждый раз увеличивайте Version code и подписывайте тем же
  ключом.
