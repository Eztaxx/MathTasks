# Одна контрольная работа для MathTasks

Один запуск — одна работа: один вариант (A или B) по одной теме. Работаешь сам, без вопросов: по расписанию спросить некого. Если что-то не получается — закрой запуск как неудачный, а не публикуй сомнительное.

**Границы.** Меняется только база (новые задания-черновики и одна работа), и только через скрипты этого скилла. Никаких коммитов, пушей, правок файлов репозитория, рисунков, новых тем и подтем. Чужие работы и задачи не трогать. Все команды — инструментом Bash из корня репозитория (`C:\Users\goga8\Downloads\MathTasks`), ровно в том виде, как написано ниже. В Bash — только команды `node .claude/skills/add-papers/scripts/…` из этого файла: ничего другого ни для правки, ни для проверки или расчёта (`python`, `grep`, `ls`, `cat`, heredoc, `node -e`). Такие команды не входят в разрешённые: запуск без людей встаёт на вопросе о разрешении и держит замок потока. Файлы — только инструментами Read, Write и Edit.

## 1. Выбор темы

```bash
node .claude/skills/add-papers/scripts/pick.mjs
```

Если задание расписания называет классы потока («поток: --grades 10»), добавь их ровно так: `pick.mjs --grades 10`.

- Код 3 «ЗАНЯТО» — идёт предыдущий запуск потока. Код 4 «ВСЁ СОСТАВЛЕНО» — у всех тем есть варианты A и B. Код 5 «ПАУЗА» — владелец поставил паузу. Во всех трёх случаях сделай шаг 6 и закончи отчётом в одну-две строки.
- «НЕЗАВЕРШЁННЫЙ ЗАПУСК … уже вставлен» — выполни `publish.mjs <запуск>`, перескажи итог и закончи. Без слов «уже вставлен» — продолжай с шага 2 по напечатанному контексту.
- Иначе скрипт создал запуск (`ЗАПУСК 20261125-0800-pall`) и напечатал задание: работу и её слаг, тему, описание темы, число заданий и смесь сложности, подтемы с кодами и сколько заданий примерно на каждую, а также либо задания уже готового варианта этой темы (тогда пишешь параллельный), либо образцы уровня из опубликованных задач подтем.

## 2. Правила

Прочитай `.claude/skills/add-papers/rules.md` целиком — каждый раз. Он ссылается на разделы `.claude/skills/add-tasks/rules.md` — прочитай и их.

## 3. Работа

В своём scratchpad создай инструментом **Write** два файла:

- `paper.mjs` — задания по плану pick.mjs (формат в rules.md);
- `verify.py` — независимый пересчёт ответа каждого задания; последняя строка вывода — JSON {короткое название: значение ученика}.

Перед проверкой перечитай работу как ученик и как учитель: данных хватает, ответ единственный, решение приходит к ответу, каждое задание по своей подтеме и по программе класса, задания не подсказывают ответы друг другу, работа решается за 45 минут.

## 4. Проверка

```bash
node .claude/skills/add-papers/scripts/check.mjs <запуск> <папка scratchpad>
```

Код 0 — чисто. Код 2 — список проблем: исправь файлы инструментом **Edit** и запусти снова. Расхождение пересчёта — повод заново решить задание, а не подогнать verify.py. Задание, которое не удаётся довести за пару попыток, замени другим той же подтемы. Не больше 5 прогонов; если чистой работы так и не вышло:

```bash
node .claude/skills/add-papers/scripts/finish.mjs <запуск> --failed "кратко, что не вышло"
```

и закончи отчётом. Чистый прогон — вставка черновиков:

```bash
node .claude/skills/add-papers/scripts/check.mjs <запуск> <папка scratchpad> --insert
```

Ненулевой код у `--insert` — вставка не прошла: выполни `finish.mjs <запуск> --failed "вставка: <причина из вывода>"`, сделай шаг 6 и закончи. После вставки check.mjs для этого запуска больше не запускай — только `publish.mjs`.

## 5. Публикация

```bash
node .claude/skills/add-papers/scripts/publish.mjs <запуск>
```

Код 0 — работа на сайте, замок снят («видимость не подтверждена» — тоже публикация, её перепроверит audit.mjs). Код 2 — не опубликовано: перескажи причину из вывода и закончи (черновики посетителю не видны; разберёт человек). Не повторяй публикацию в цикле.

## 6. Самопроверка автозапуска

```bash
node .claude/skills/add-papers/scripts/audit.mjs
```

Код 2 — замечания: ничего не исправляй сам, просто перенеси их в отчёт. Делай этот шаг и тогда, когда pick.mjs сказал «ЗАНЯТО», «ВСЁ СОСТАВЛЕНО» или «ПАУЗА».

## 7. Отчёт

Две-четыре строки: какая работа (слаг и ссылка `https://mathtasks.lv/control-work/<слаг>`), сколько заданий, итог публикации, замечания audit.mjs.
