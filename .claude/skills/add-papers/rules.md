# Правила контрольной работы

Общие правила задач — в `.claude/skills/add-tasks/rules.md`: прочитай оттуда разделы **«verify.py — независимый пересчёт»**, **«Поле ответа»**, **«Тексты»** и **«Программа по классам»** — они действуют и здесь. Ниже — чем контрольная отличается.

## Отличия от пачки задач

- **Только латышский.** Решение владельца: в работе нет русского текста (скрипт кладёт латышский и в русские поля). Никакой кириллицы ни в одном поле.
- **Только числовой ответ.** Задач с самопроверкой нет: каждое задание сайт сверяет сам. Утверждение «верно ли» → «Kurš no apgalvojumiem ir patiess? … Atbildē uzrakstiet apgalvojuma numuru.» с ответом `$\text{Numurs} = 2$`.
- **Без рисунков.** Диаграммы и чертежи — словами и данными: таблица частот строкой, координаты точек, «augšā — …, apakšā — …» не нужно. Никаких «attēlā», «zīmējumā».
- **Без подсказок.** Поля подсказки нет.
- **Обращение.** 5–6 класс — на «ты» (Aprēķini, Atrodi), 7–12 — на «вы» (Aprēķiniet, Atrodiet).

## Файл paper.mjs

```js
export default [
  {
    sub: '10.3.2',                                   // код подтемы из pick.mjs
    title: 'cena pēc divām atlaidēm',                // коротко, по-латышски, без префикса «KD …»
    c: String.raw`Jaka maksāja $80$ eiro. Cenu samazināja par $10\%$, pēc tam vēl par $5\%$. Aprēķiniet jakas jauno cenu eiro.`,
    a: String.raw`$\text{Cena} = 68{,}4$`,
    s: String.raw`1) Pēc pirmās atlaides: $80 \cdot 0{,}9 = 72$.
2) Pēc otrās: $72 \cdot 0{,}95 = 68{,}4$.
Atbilde: $68{,}4$.`,
    d: 'Средний'                                     // Лёгкий | Средний | Сложный
  },
  // …
];
```

- Поля — ровно `sub`, `title`, `c`, `a`, `s`, `d`. Тексты — через `String.raw`, обратный слэш одинарный.
- Название — по смыслу задания, уникально в работе; скрипт добавит префикс `KD 10.3 A:`.
- Решение — шаги `1) … 2) …`, последняя строка `Atbilde: …` с тем же числом, что в ответе.
- Подпись ответа — латинскими буквами в `\text{}`: `Cena`, `Laukums`, `Varbūtība`, `Skaits`, `Numurs`, `Vērtība`.

## verify.py

Ключ JSON — **короткое название** задания (как в `title`, без префикса), значение — что ученик впишет в поле, по правилам add-tasks (`"68.4"`, `"9/20"`, `"2sqrt(3)"`). Считать из данных условия другим способом, чем решение; переписать ответ литералом — не проверка.

## Состав работы

- **18–22 задания**, 45 минут. Порядок — от лёгкого к трудному внутри каждого блока, блоки — по подтемам в порядке pick.mjs.
- **Каждая подтема** темы — хотя бы одно задание; где подтем мало — несколько разных типов на подтему.
- **Сложность:** примерно 40 % лёгких, 40 % средних, 20 % сложных (pick.mjs печатает числа). Сложное — в два-три действия, а не громоздкие вычисления.
- **Разнообразие.** Не два одинаковых упражнения с другими числами. Можно два-три задания на общих данных (одна таблица — мода, медиана, среднее), но **ни одно условие не подсказывает ответ другому**: не писать в условии число, которое является ответом соседнего задания (не «vismaz $25$ punktus», если $25$ — это $Q_3$ из прошлого задания, а «vismaz tikpat, cik trešā kvartile»).
- **Однозначность.** Утверждения в задании «kurš patiess» — заведомо истинное ровно одно, ложные опровергаются данными, а не «не следует из данных». Полуинтервалы — `[a; b)`, и граничные значения в данных проверяют оба конца.
- **Время.** Устный счёт и одна-две строки записи на лёгкое задание; работа целиком — на 45 минут для среднего ученика.

## Вариант B

Если pick.mjs напечатал задания уже готового варианта этой темы — пиши **параллельный**: те же типы заданий в том же порядке и той же трудности, другие числа и сюжеты. Ни одно условие не повторять (check.mjs сверяет). Ответы вариантов не должны совпадать подряд — у соседа по парте другой вариант.

## Латышский

Падежи и согласование числительных: «$30$ skolēni», «$68$ mēģinājumi», «$21$ reize» (на 1, кроме 11, — единственное число); «Cik skolēnu …?»; «no tām» для женского рода (serves, bumbiņas). «Nevienā» слитно. Термины Skola2030: šķēlums, apvienojums, starpība, apakškopa, kopa, relatīvais biežums, moda, mediāna, kvartile, starpkvartiļu izkliede, amplitūda, izlase, ģenerālkopa, normālforma. Без калек с русского («ienāca klasē» → «pievienojās klasei», «pie kādas vērtības» → «kurai vērtībai»).
