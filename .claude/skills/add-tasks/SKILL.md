# Пачка новых задач для MathTasks

Один запуск — одна пачка (до 8 задач) в одну подтему. Работаешь сам, без вопросов: по расписанию спросить некого. Если что-то не получается — закрой пачку как неудачную, а не публикуй сомнительное.

**Границы.** Меняется только база задач, и только через скрипты этого скилла. Никаких коммитов, пушей, правок файлов репозитория, новых подтем, картинок. Чужие и старые задачи не трогать. Все команды — инструментом Bash из корня репозитория (`C:\Users\goga8\Downloads\MathTasks`), ровно в том виде, как написано ниже.

## 1. Выбор подтемы

```bash
node .claude/skills/add-tasks/scripts/pick.mjs
```

- Код 3 «ЗАНЯТО» — идёт другой запуск. Код 4 «ВСЁ ЗАПОЛНЕНО» — во всех подтемах уже по 15 задач. В обоих случаях сделай шаг 6 и закончи отчётом в одну-две строки.
- «НЕЗАВЕРШЁННАЯ ПАЧКА» — выполни показанную команду `publish.mjs <пачка>`, перескажи итог и закончи.
- Иначе скрипт создал пачку (`ПАЧКА 20261012-1500`) и напечатал контекст: подтему, тему, программу, соседние подтемы, уже имеющиеся задачи и два образца оформления. Это и есть задание.

## 2. Правила

Прочитай `.claude/skills/add-tasks/rules.md` целиком — каждый раз. Там формат файла, допустимые формы ответа, требования к LV и что есть и чего нет в программе каждого класса.

## 3. Пачка

В своём scratchpad (а если его нет — в `.claude/skills/add-tasks/state/batches/<пачка>/`) создай инструментом **Write**:

- `tasks.mjs` — столько задач, сколько просит pick.mjs («Написать задач: N»), все с `sub` выбранной подтемы. Разные типы, смесь сложности, ничего не повторяет существующие задачи подтемы.
- `verify.py` — независимый пересчёт ответа каждой задачи; последняя строка вывода — JSON со значениями полей ответа (формат в rules.md).

Перед проверкой перечитай каждую задачу как ученик: данных хватает, ответ единственный, решение приходит к ответу, латышский текст — точный перевод русского, задача по программе класса и по этой подтеме.

## 4. Проверка

```bash
node .claude/skills/add-tasks/scripts/check.mjs <пачка> <папка с tasks.mjs и verify.py>
```

Код 0 — чисто. Код 2 — список проблем по задачам: исправь файлы (Edit) и запусти снова. Расхождение пересчёта — повод заново решить задачу, а не подогнать verify.py. Если задачу не удаётся довести за пару попыток — удали её из tasks.mjs (и её значение из verify.py, перенумеровав ключи). Не больше 5 прогонов; если чистой пачки так и не вышло:

```bash
node .claude/skills/add-tasks/scripts/finish.mjs <пачка> --failed "кратко, что не вышло"
```

Если сама подтема не годится для задач с автопроверкой — `finish.mjs <пачка> --skip-sub "причина"`.

## 5. Вставка и публикация

```bash
node .claude/skills/add-tasks/scripts/check.mjs <пачка> <папка> --insert
node .claude/skills/add-tasks/scripts/publish.mjs <пачка>
```

`--insert` ещё раз проходит все проверки и пишет задачи черновиками. `publish.mjs` перечитывает их из базы, публикует чистые, перенумеровывает тему и проверяет страницы `mathtasks.lv/ru/task/<id>` и `/task/<id>`. После `--insert` tasks.mjs не править: publish.mjs сверяет базу с файлом и расхождение оставит черновиком.

## 6. Проверка автозапуска

```bash
node .claude/skills/add-tasks/scripts/audit.mjs
```

Перепроверяет последние 40 задач, выложенных скиллом (опубликованы, робот и KaTeX чистые, названия не повторяются, страницы на сайте открываются), и сам автозапуск (давно ли была удачная публикация, нет ли неудач подряд, брошенного замка, застрявших черновиков). Код 2 — замечания: ничего не исправляй сам, просто перенеси их в отчёт. Делай этот шаг и тогда, когда pick.mjs сказал «ЗАНЯТО» или «ВСЁ ЗАПОЛНЕНО».

## 7. Итог

Короткий отчёт пользователю (2–4 строки): подтема (код и название), сколько задач опубликовано и их id, что осталось черновиком или не получилось и почему, замечания audit.mjs (если есть). Журнал всех запусков: `node .claude/skills/add-tasks/scripts/pick.mjs --status`.

## Справка

- Состояние — `.claude/skills/add-tasks/state/` (не в git): `lock.json`, `log.jsonl`, `skip.json`, `batches/<пачка>/`.
- Настройки — в начале `scripts/common.mjs`: классы `GRADES`, потолок `TARGET` = 15, размер пачки `PER_RUN` = 8.
- Замок держится до конца запуска; брошенный (старше 75 минут) pick.mjs снимает сам. Снять вручную: `finish.mjs --unlock`.
- Подтема, где два запуска подряд кончились неудачей, больше не выбирается, пока её не уберут из журнала.
