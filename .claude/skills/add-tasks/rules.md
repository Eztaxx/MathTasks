# Правила задач MathTasks

Собраны из выпуска ~2600 задач (сентябрь–октябрь 2026). Каждое правило уже однажды стоило ошибки на сайте.

## Файл tasks.mjs

Писать только инструментом **Write** (heredoc и `node -e` съедают обратные слэши: `\text` превращается в табуляцию). Все поля с LaTeX — через `String.raw`, слэш одинарный.

```js
const R = String.raw;
export default [
  {
    sub: 127, d: 'Лёгкий',                       // id подтемы из pick.mjs; 'Лёгкий' | 'Средний' | 'Сложный'
    t: 'Сумма смешанных чисел с общим знаменателем',
    tl: 'Jauktu skaitļu summa ar kopīgu saucēju',
    c: R`Вычисли $1\frac{3}{8} + 2\frac{7}{8}$. Ответ запиши смешанным числом.`,
    cl: R`Aprēķini $1\frac{3}{8} + 2\frac{7}{8}$. Atbildi pieraksti kā jauktu skaitli.`,
    a: R`$\text{Сумма} = 4\frac{1}{4}$`,
    al: R`$\text{Summa} = 4\frac{1}{4}$`,
    s: R`1) Сложим целые части: $1 + 2 = 3$.
2) Сложим дробные части: $\frac{3}{8} + \frac{7}{8} = \frac{10}{8} = 1\frac{1}{4}$.
3) $3 + 1\frac{1}{4} = 4\frac{1}{4}$.
Ответ: $4\frac{1}{4}$.`,
    sl: R`1) Saskaitām veselās daļas: $1 + 2 = 3$.
2) Saskaitām daļas: $\frac{3}{8} + \frac{7}{8} = \frac{10}{8} = 1\frac{1}{4}$.
3) $3 + 1\frac{1}{4} = 4\frac{1}{4}$.
Atbilde: $4\frac{1}{4}$.`,
    h: R`Сложи отдельно целые и дробные части, потом выдели целое из неправильной дроби.`,
    hl: R`Saskaiti atsevišķi veselās daļas un daļas, pēc tam izdali veselo no neīstās daļas.`
  },
];
```

- Необязательные `chk` / `chkl` — дополнительные варианты сверки ответа (по одному на строку). Обычно не нужны.
- Решение: шаги отдельными строками `1) … 2) …`, последняя строка `Ответ: …` / `Atbilde: …` с теми же числами, что в поле ответа (робот сверяет). Латышское решение — полный перевод русского, не короче.
- Без Markdown (`**`), HTML и пустых строк между шагами.

## verify.py — независимый пересчёт

- Считает ответ **из данных условия другим способом**, чем решение: перебор, координаты, моделирование, `fractions.Fraction`, подстановка корней в уравнение, численная проверка неравенства на сетке точек. Переписать ответ числом-литералом — не проверка.
- Только стандартная библиотека Python (numpy нет).
- Последняя строка вывода — JSON: ключ — номер задачи в tasks.mjs с 1, значение — список строк, **что ученик впишет в поля ответа**:
  - целое `"16"`, десятичное `"2.5"`, дробь `"25/3"` (из `Fraction`), смешанное `"4 1/4"`;
  - π и корни: `"45pi"`, `"64-16pi"`, `"2sqrt(3)"`; стандартный вид — `"4.5*10^4"` (не `"45000"`);
  - точка или пара — два поля: `["2", "-1"]`; несколько подписанных величин — по полю на каждую в порядке ответа: `["3", "5"]`; корни — по возрастанию;
  - процент, угол в градусах, длина в см — только число: `"15"`, `"108"`, `"24"`.
- check.mjs сверяет значения функцией сайта (как ответ ученика), а значение на единицу больше должно быть отвергнуто.

## Поле ответа

Ответ — всегда с подписью, которая называет то, что спрашивают: `$\text{Площадь} = 24\text{ см}^2$`, `$x = 5$`, `$AB = 7$`, `$\angle C = 108^\circ$`.

Проходят: число, дробь `R = \dfrac{25}{3}`, смешанное число, десятичная `2{,}5`, `45\pi`, `64 - 16\pi`, `4{,}5 \cdot 10^{4}`, `2\sqrt{3}`, точка `\text{Вершина} = (2; -1)`, пары `(1; 4), (6; 1)`, корни `x_1 = -3; \; x_2 = 5`, номер варианта `\text{Номер} = 2`, единицы `\text{ см}`, `\text{ cm}^2`.

Не проходят — робот не сверит, у ученика будет «самопроверка» или пустое поле:
- подпись-формула: `\sin 2\alpha = …`, `a + b = 5`, `(a+b)^2 = 32`, `f(2) = …`, `R^2`, `P(A|B)` → `\text{Значение}`, `\text{Сумма в квадрате}`, `\text{Вероятность}`;
- подпись с цифрами (`\text{Аварий на 1000}`) или слишком длинная (`\text{Площадь боковой поверхности}` → `\text{Боковая поверхность}`, `\text{Число последовательностей}` → `\text{Число вариантов}`);
- выражение без подписи (`a^2 - 2a`) → `\text{Частное} = a^2 - 2a`, а лучше спросить значение при данном `a`;
- слово как значение (`\text{Город} = \text{Даугавпилс}`), «да/нет» → спросить число: сколько, наибольшее, наименьшее, номер варианта;
- модуль в ответе `|\vec{a} + \vec{b}|` → `\text{Длина суммы} = 13`;
- уравнение окружности или прямой → спросить центр и радиус, угловой коэффициент;
- промежуток как ответ (`A \cap B = (1; 5)`, решение неравенства) — сайт рисует два поля как у точки → спросить длину промежутка, число целых решений, наименьшее целое решение;
- точка со штрихом `A'(-1; 3)` → `\text{Образ} = (-1; 3)`;
- единицы J, Дж, мин, dB, «ч 30 мин» → единицу в условие («в джоулях», «в минутах»), в ответе только число;
- формат дроби всегда задавать в условии: «несократимой дробью», «смешанным числом», «десятичной дробью».

## Тексты

- Числа — цифрами в обоих языках, одинаковые в RU и LV: «за $2$ года» → «$2$ gados», не «divos gados» (робот сравнивает числа условия и ответа).
- Кириллица и латышские буквы внутри формулы — только в `\text{}`: `S_{\text{осн}}`, `\text{В} - \text{Р}`. Знак «€» не писать — «евро» / «eiro».
- Проценты — только в формуле и со слэшем: `$20\%$`.
- Команды LaTeX — только внутри `$…$`.
- Название — по смыслу задачи, до ~70 знаков, уникально по всей базе на обоих языках (при совпадении переименовать). Не «Задача №N».
- Подсказка — направление, а не результат: без чисел ответа, до 360 знаков.
- Чертежей автозапуск не делает. Условие должно читаться без рисунка: вершины и точки названы, ясно, какой катет, где точка, координаты даны. Никаких «на рисунке».
- Латышский: 5–6 класс — на «ты» (Aprēķini, Atrodi, Uzraksti), 7–12 — на «вы» (Aprēķiniet, Atrodiet). Следить за падежами и числом (rombs → romba mala, loceklis → locekļi). Термины: pamati (основания), sānu mala, viduslīnija, amplitūda (размах), normālforma (стандартный вид), ģerbonis/cipars (орёл/решка), iznākums, labvēlīgi notikumam, relatīvais biežums.
- Контексты — латвийские и бытовые (eiro, Rīga, skola, veikals), числа «красивые», ответ однозначный.

## Программа по классам

Держаться названия подтемы и не залезать в соседние подтемы темы (pick.mjs печатает их список).

- **5–6 класс.** Вне тем про дроби — только целые числа: робот (код `young`) ругается на `\frac`, десятичные и «n/m», если в названии темы нет «дроб/процент/смешанн». Совместная работа в 6.1 — через «условные единицы» (всю работу = общее кратное времён), без дробей.
- **7 класс.** Skola2030: множества и вероятность, геометрические фигуры, зависимости величин, линейная функция, треугольник, выражения с переменной, линейные уравнения, неравенства. Без квадратных уравнений (это 8–9 класс).
- **8 класс.** Без дискриминанта и формулы вершины (это 9 класс): вершину и наибольшее значение — через нули и симметрию; графическое решение уравнений — по таблицам значений.
- **9 класс.** Подобие, тригонометрия прямоугольного треугольника, квадратичная функция, дробные выражения. Олимпиадные подтемы 9.9.x — ответ числом (наименьшее/наибольшее/сколько), verify.py — полным перебором.
- **10 (Vispārīgais, общий уровень).** Без независимых событий и произведения вероятностей. Комбинаторика — правилами суммы и произведения и перебором, без формул перестановок и сочетаний. Ноль к натуральным не относится. Вероятность — десятичной или обыкновенной дробью, формат в условии.
- **11 (Matemātika I, оптимальный уровень).** Нет: модуля в уравнениях, теоремы Безу и возвратных уравнений, логарифмических уравнений и логарифмической функции, арифметической прогрессии, бесконечной геометрической прогрессии, асимптот. Анаграммы — только из разных букв (перестановок с повторениями нет).
- **12 (Matemātika II, высший уровень).** По названию темы и подтемы: модуль, иррациональные и логарифмические уравнения, пределы, производная, интеграл, комбинаторика и вероятность.

## Когда подтема не годится

Если по подтеме нельзя написать задачи с числовым ответом, который сверяется автоматически (только построения, доказательства, проект, работа с реальным чертежом), — не выдумывать: `finish.mjs <пачка> --skip-sub "причина"`, и pick.mjs больше её не выберет.

## Качество пачки

- Разные типы: не восемь копий одного упражнения с другими числами. Смесь сложности примерно 3 «Лёгкий», 3 «Средний», 2 «Сложный» с поправкой на то, чего в подтеме уже много.
- Не повторять задачи подтемы, которые печатает pick.mjs (тот же тип с теми же числами).
- Перед check.mjs перечитать каждую задачу глазами ученика: все данные есть, ответ один, решение доходит до ответа, LV — точный перевод.
